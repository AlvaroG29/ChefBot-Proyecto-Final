## Descripción

ChefBot es un robot mesero que identifica platillos a partir de fotografías y los entrega
a la mesa correcta en un restaurante simulado. El proyecto se construye en 4 entregas:

1. **Entrega 1:** Datos, aprendizaje supervisado y no supervisado (esta entrega)
2. **Entrega 2:** Redes neuronales convolucionales (CNN)
3. **Entrega 3:** Aprendizaje por refuerzo
4. **Entrega final:** Integración, informe y demo

## Dataset

[Food-101](https://www.kaggle.com/datasets/dansbecker/food-101): subconjunto de 10 clases
(≈1,000 imágenes por clase): pizza, hamburger, sushi, caesar_salad, tacos, ice_cream,
spaghetti_bolognese, omelette, chocolate_cake, hot_and_sour_soup.

## Cómo ejecutar

1. Abrir el notebook en Google Colab.
2. Ejecutar todas las celdas en orden (Entorno de ejecución > Ejecutar todo).
3. Para ejecutarlo en local: `pip install -r requirements.txt`

Se usa la semilla aleatoria `42` en todo el proyecto para que los resultados sean reproducibles.
